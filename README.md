# CMMC Control Validation — interactive prototype

A live, self-contained demo: pick a CMMC / NIST 800-171 control, watch it evaluate
against an illustrative environment, and see the exact violating record as evidence.

Machine-checked control validation — proposer (AI drafts) → verifier (grounded against
the real NIST text) → human sign-off → deterministic checker. Synthetic data only;
prototype, not an official assessment.
